Gemini → Excel → Examination Portal

Ask Gemini to create the examination as an .xlsx workbook using the portal's required columns, then have your connected MCP client call upload_exam_excel. The upload is saved as a draft. Check the answer key, marks and questions below, then publish it yourself.

Required Excel columns: question, type, marks, answer. Optional MCQ columns: option_a, option_b, option_c, option_d. Supported types: mcq, fill, text.

The MCP client needs PORTAL_BASE_URL and MCP_API_TOKEN in its own private configuration. Students never need either credential.
